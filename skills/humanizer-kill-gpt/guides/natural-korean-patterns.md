# 자연스러운 한국어 종결·패턴 레퍼런스 (대안 생성의 근거)

GPT 티를 제거한 뒤 그 자리를 채울 대안은 아래 자연스러운 한국어 패턴 안에서 고른다. GPT는 단정을 피하고 유보를 겹치며 어색한 연결어를 끼워넣는 경향이 있는데, 이 파일은 한국어 원어민이 실제로 쓰는 종결/연결/리듬을 제시해 그 빈자리를 메우는 기준이 된다. 카탈로그(SKILL.md)는 "무엇을 빼는가"의 방향만 주고, 최종 표현의 결은 여기에서 맞춘다.

## 1. 문장 종결 (상황별로 골라 씀)

| 용도 | 자연스러운 종결 | 메모 |
|---|---|---|
| 사실 단정 | `~입니다`, `~합니다`, `~았습니다`, `~음` | 사실이면 끝까지 단정. 유보로 흐리지 말 것 |
| 의견 | `~라고 생각합니다`, `~인 것 같습니다` | GPT의 `-로 봤습니다`/`-라고 봅니다` 대체 |
| 추정/완곡 | `~같습니다`, `~듯합니다`, `~ㄹ 것 같습니다` | 본인 추정·심정에만. 사실 판단엔 쓰지 말 것 |
| 구어 완충 | `~네요`, `~거든요`, `~더라고요`, `~아서요` | 감정·배경 설명에 자연스러움 |
| 정중한 약반박 | `~잘 모르겠습니다`, `~받아들이기 어렵습니다`, `~뭐가 문제인지 모르겠습니다` | 약한 척하지만 분명히 반박하는 한국어식 표현 |

## 2. 연결어 (자연 vs GPT 어색)

- 자연스러운 연결: `그리고`, `근데` / `그런데`, `다만`, `그래서`, `왜냐하면` / `왜냐면`, `참고로`, `한편`, `오히려`
- GPT가 어색하게 끼워넣는 것(→ 삭제하거나 위로 대체): `흐름 안에서`, `그 위에서`, `~하나로 묶어` 같은 추상 연결
- 한 문장에 유보 연결을 겹치지 말 것: `~으로는 ~지만, ~지는 않았습니다` 구조는 한 번만.

## 3. 본론 진입 / 짚기 (예고 표현)

긴 글에서 한국어는 본론 들어가기 전에 예고를 자주 붙인다. GPT는 이 예고 없이 바로 결론을 던져 딱딱해진다.

- "먼저 ~부터 말씀드리겠습니다"
- "한 가지 짚어두겠습니다" / "한 가지만 더 말씀드리겠습니다"
- "마지막으로 ~"
- "정리하면 ~"

## 4. 요청 / 제안 (정중하되 군더더기 없이)

- `~주시면 좋겠습니다`, `~주시면 감사하겠습니다`, `~부탁드립니다`
- 의견 묻기: `~어떻게 생각하세요?`, `~괜찮을까요?`
- 청유형 `-합시다`는 기계적이라 피하고 위 형태로.
- corporate softener(`양해 부탁드립니다`, `바쁘신 와중에`, `혹시 괜찮으시다면`)를 다시 끼워넣지 말 것. 정중함은 한 군데만 깔끔하게.

## 5. 사과 (조건부 가짜 사과 금지)

- `~점 사과드립니다`, `~점 죄송합니다`
- 잘못이 명확하면 흐리지 말고 명확히 인정: "결과적으로 ~는 명백히 저희 잘못이라고 생각합니다"
- `~처럼 들리셨다면 죄송합니다` 식의 조건부 가짜 사과는 쓰지 말 것.

## 6. 리듬 (문장 길이 섞기)

- 짧은 단정문과 긴 설명문을 섞는다. GPT는 비슷한 길이의 유보문이 줄줄이 이어져 단조롭다.
- 한 문장 안에 `정도` / `수준` / `쪽` 같은 GPT 버릇 단어를 겹쳐 쓰지 말 것. 숫자나 사실은 직접 제시.

## 대안 생성 시 핵심

의미는 유지하고, 종결·연결·정중함의 결만 위 패턴으로 맞춘다. GPT 티 하나를 다른 GPT 티로 바꾸지 않도록, 대안을 SKILL.md 카탈로그 전체와 한 번 더 대조한 뒤 확정한다.
